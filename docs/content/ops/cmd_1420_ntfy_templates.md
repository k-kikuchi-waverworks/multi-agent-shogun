# 殿へ送る通知の型（cmd_1420）

殿の基準（CLAUDE.md 冒頭）は4つ。**題は20字以内／本文は3行以内／平易な言葉／記号を並べない**。

`scripts/ntfy.sh` は送る前にこれを検め、外れていれば画面に出す。**送信は止めない**
（止めると急ぎの知らせが文体のせいで届かなくなるため）。この紙は `bash scripts/ntfy.sh --templates` でも読める。

なぜ要るか：2026-07-27 の実測（軍師二号）で、殿宛ての実送信24本のうち基準を満たしたのは**3本だけ**だった。
題の平均は26字、最長41字である。

---

## 送る前に一度 自分に問うこと

> **これは30分後に覆るか。覆りうるなら送らない。**

同日の訂正6本は、すべて「まだ固まっていない話を送った」ことが原因だった。
固まる前の話は dashboard に書けばよい。**dashboard は上書きできるが、殿の端末に届いた通知は取り消せない。**

---

## 型1 — 完了報告

```
題: ✅ 恋の学習データ 450 対 完了
本文:
  b15 まで着地。テストは全て通っています。
  次は b16 の予定です。
  詳しくは dashboard をご覧ください。
```

入れるもの：何が終わったか、次に何をするか。
入れないもの：途中経過、技術用語、コミット番号。

## 型2 — 殿の作業のお願い

```
題: 🔑 殿の作業 1 件（5 分）
本文:
  株のサーバを常駐で立ち上げ直してください。
  これをしないと明朝の画面が昨日のままになります。
  手順は dashboard の「殿の手番」に書いてあります。
```

入れるもの：何をするか、しないとどうなるか、所要時間。
入れないもの：なぜそうなったかの経緯。

## 型3 — ご判断のお願い

```
題: 🚨 ご判断をお願いします 1 件
本文:
  恋の反応速度を上げると、代わりに会話の質が少し落ちます。
  どちらを取るか、お決めいただきたく存じます。
  選択肢と根拠は dashboard の「要対応」にあります。
```

入れるもの：何を選ぶのか、どちらに何を失うか。
入れないもの：選択肢を全部書くこと（本文3行に入らない）。

## 型4 — 手が止まった時

```
題: ⛔ 作業が止まりました（GPU）
本文:
  ComfyUI が GPU を掴んだままで、学習が始められません。
  殿に閉じていただく必要があります。
  他の作業は続いています。
```

入れるもの：何が止まったか、誰が動かせるか、他は動いているか。

## 型5 — 訂正

```
題: ✂️ 訂正 — 株の作業は 1 回だけ
本文:
  16:47 の通知を訂正します。
  発掘のやり直しは不要でした。常駐化だけで済みます。
  お手数をおかけしました。
```

**この型を使うのは、前の通知が間違っていた時だけである。** 内容が育っただけなら送らない。

## 書き直しの例（実際に送られたもの）

| 元の題 | 書き直し |
|---|---|
| ☀️ 夜明けの報 — 殿の手番は5つ・朝の門が1つ鳴りました | ☀️ 朝の報告 — 殿の作業 5 件 |
| 🚨 殿の手番が一つ増え申した (A-6) — 恋の頭脳 v7.1 に… | 🚨 殿の作業が 1 件 増えました |
| 👁️ 比較の束が整い申した (殿の目でお読みくだされ) | 👁️ 比較の資料ができました |
| 株T3 P1着地 — 而してデータ不足 55.8% | ✅ 株 T3 完了（データ不足 56%） |

## 道具が何を見ているか

| 見るもの | 外れとする条件 |
|---|---|
| 題の字数 | 20字を超える。**コードポイントで数え、絵文字は1字**（ZWJ で繋いだ絵文字は複数字になる） |
| 本文の行数 | 3行を超える |
| 記号 | 題に `【` `】` `★` が入る、または同じ記号が2つ続く |
| 文語調 | 申し／ござ／而して／拙者／貴殿／候／なされ |
| 身内の言い回し | 伏せ札／秤／関所／番人／錨／牙／門 |

**文字列はそのまま見る。** バッククォートで囲んでも通らない
（同じ穴を engine 側で 2026-07-27 に実際に踏んだため、ここでは作らない）。

判定の結果はログにも `style=` として残る（外れが無ければ `style=ok`）。
後から「守られているか」を数で見るためである。

## 限界

- 見ているのは形だけである。**中身が殿に必要な知らせかは判定できない**（内部の進行実況などは人が判断する）。
- 語の一覧は本日の実測から作った。ここに無い言い回しは通る。**通ったことは「読みやすい」の証明ではない**。
